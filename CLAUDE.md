# Claude Code

@AGENTS.md

Dette importerer den felles prosjektveiledningen i Claude Code. Les også fagfilene
som AGENTS.md angir for oppgaven. Ikke opprett en parallell kopi av emnereglene her.
Importen er veiledning i konteksten, ikke en teknisk håndheving av reglene.

Søsterrepoet `../School` (privat) har ferske Canvas-uttrekk, sign-off-notater og lærerens
Fullstækk-kurs. Se etter der før krav-, plan- og reviewarbeid, som AGENTS.md beskriver.
Bare lesing, og kursmateriell kopieres aldri hit.
Vanlig Claude-chat og ChatGPT må få relevant innhold uttrykkelig, se
[assistentbruk](docs/prosess/assistentbruk.md).

## Utfordre valgene (Max 05.10)

Ved hvert valg vi tar, unntatt de helt opplagte: grill brukeren før valget gjennomføres.
Still spørsmål som får frem begrunnelsen (hvorfor dette, hvilke alternativer, hva koster det,
hvordan testes det), og la studenten forsvare valget med egne ord. Ikke gi svaret selv; pek
på svakheter og spør videre til begrunnelsen holder. Noter valget og begrunnelsen i riktig
dokument eller i endringsloggen. Opplagt betyr at det følger direkte av krav, kurs eller
eksisterende kode og ikke har reelle alternativer.

Emil bruker ikke Claude; valg som tas her, tas av Max.
